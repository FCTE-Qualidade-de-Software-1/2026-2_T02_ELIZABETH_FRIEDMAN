- Compila no **Overleaf** com o compilador **XeLaTeX** (Menu → Compiler). Não use pdfLaTeX.

Para atualizar o PDF, copie `main.tex` e `refs.bib` para o projeto do Overleaf e recompile. Se as referências aparecerem como `?`, use **Recompile from scratch**.
