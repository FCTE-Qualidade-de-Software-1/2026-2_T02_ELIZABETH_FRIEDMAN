## Sobre o projeto

Este repositório reúne o projeto final da disciplina: uma avaliação da qualidade do produto
[Sua Grade UnB](https://suagradeunb.com.br/), aplicação web que ajuda estudantes da UnB a montar a
grade horária do semestre sem conflitos de horário. O sistema foi criado em 2023 na disciplina de
Métodos de Desenvolvimento de Software e tem código aberto em
[unb-mds/2023-2-SuaGradeUnB](https://github.com/unb-mds/2023-2-SuaGradeUnB).

A avaliação segue o processo da ISO/IEC 25040, usa o modelo de qualidade da ISO/IEC 25010:2023 e
define as métricas pelo método GQM (*Goal–Question–Metric*). O andamento do projeto é acompanhado
com métricas do PSM/CID.

Características avaliadas, em ordem de prioridade:

1. Manutenibilidade
2. Capacidade de interação (Usabilidade)
3. Eficiência de desempenho
