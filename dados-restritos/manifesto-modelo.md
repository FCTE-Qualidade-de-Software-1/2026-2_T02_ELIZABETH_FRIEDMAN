# Modelo de manifesto da sessão

Copiar este modelo para `dados-restritos/` e preencher uma cópia por configuração.
Este é um formulário vazio, sem validação ou execução implícita. Não colocar senhas,
tokens, nomes reais ou links privados na documentação pública.

| Campo | Preenchimento pela equipe |
|---|---|
| ID da configuração / versão do protocolo | Pendente |
| Data / moderador / observador | Pendente |
| URL privada acessível no dispositivo do participante | Pendente |
| Commit do produto | `3d399e745383b05e8e3b1a7c97ac0fdbf93a0360` |
| Dispositivo físico / modelo / sistema operacional | Pendente |
| Navegador / versão / resolução / viewport | Pendente |
| Modalidade: navegador ou conta | Pendente |
| Identificador da conta descartável, se aplicável | Pendente |
| Arquivo da massa / SHA-256 / ano e período carregados | Pendente |
| A1 / A2 / B1 conferidas na interface | Usar os candidatos dos cartões; registrar evidência |
| Backup restrito / passos de restauração | Pendente |
| S0 restaurado e conferido | Pendente |
| S1 restaurado e conferido | Pendente |
| G0 salva e recuperada após recarga | Pendente |
| Compartilhamento de tela no dispositivo real | Pendente |
| Captura / gravação testadas, quando autorizadas | Pendente |
| V02 visível durante as duas perguntas | Pendente |
| Retenção da resposta de geração: ferramenta, endpoint, duração e limitação | Pendente, ou não utilizada |
| Local restrito dos registros e consentimentos | Pendente |
| Revisão por integrante / liberação para piloto ou coleta | Pendente |

No computador e no celular, repetir a preparação no navegador real. Não limpar
armazenamento entre salvar G0 e verificar sua recuperação. Restaurar somente dados
de teste, sem alterar mensagens ou controles do produto.
